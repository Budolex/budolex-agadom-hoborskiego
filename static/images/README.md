### Gallery Images

## Image Guidelines

- **Format**: JPG for photos, PNG for logos/graphics with transparency
- **Quality**: High resolution, optimized for web (under 500KB each)
- **Aspect ratios**: 
  - Hero: 16:9 landscape
  - Gallery: 3:2 landscape
  - Floor plans: 4:3 or as needed for clarity
  - Logo: Square or wide rectangle, transparent background

## Optimization Tips

1. Use tools like TinyPNG or ImageOptim to compress images
2. Ensure images are web-optimized (72 DPI)
3. Use descriptive filenames
4. Keep consistent naming for unit-specific images
